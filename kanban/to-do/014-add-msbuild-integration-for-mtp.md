## Notes

### Props File Content

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- build/TimeWarp.Jaribu.TestingPlatform.props -->
<Project>

  <PropertyGroup>
    <!-- Mark as test project for IDE recognition -->
    <IsTestProject>true</IsTestProject>
    
    <!-- Enable Microsoft.Testing.Platform -->
    <IsTestingPlatformApplication>true</IsTestingPlatformApplication>
    <TestingPlatformDotnetTestSupport>true</TestingPlatformDotnetTestSupport>
    
    <!-- Build as executable (M.T.P. generates Main) -->
    <OutputType>Exe</OutputType>
    <GenerateProgramFile>false</GenerateProgramFile>
    
    <!-- Enable protocol for IDE integration -->
    <UseTestingPlatformProtocol>true</UseTestingPlatformProtocol>
    <IsTestingPlatformEnabled>true</IsTestingPlatformEnabled>
  </PropertyGroup>

  <ItemGroup>
    <!-- 
      Register the Jaribu test framework with M.T.P.
      The GUID should be unique and stable for this extension.
    -->
    <TestingPlatformBuilderHook Include="TimeWarp.Jaribu.TestingPlatform">
      <DisplayName>TimeWarp.Jaribu</DisplayName>
      <TypeFullName>TimeWarp.Jaribu.TestingPlatform.TestingPlatformBuilderHook</TypeFullName>
    </TestingPlatformBuilderHook>
  </ItemGroup>

</Project>
```

### Project File Updates

```xml
<!-- TimeWarp.Jaribu.TestingPlatform.csproj additions -->
<ItemGroup>
  <!-- Include props in both build and buildTransitive for package consumers -->
  <None Include="build/**" Pack="true" PackagePath="build/" />
  <None Include="build/**" Pack="true" PackagePath="buildTransitive/" />
</ItemGroup>
```

### How M.T.P. Uses These Properties

1. **`IsTestingPlatformApplication=true`**: Tells MSBuild to use M.T.P. infrastructure
2. **`GenerateProgramFile=false`**: Prevents SDK from generating `Main()`; M.T.P. generates it
3. **`TestingPlatformBuilderHook`**: M.T.P. looks for this item group to find framework registrations
4. **`TypeFullName`**: Points to the static class with `AddExtensions(ITestApplicationBuilder, string[])` method

### Generated Entry Point

M.T.P. generates something like:

```csharp
// Auto-generated by Microsoft.Testing.Platform.MSBuild
public static class Program
{
    public static async Task<int> Main(string[] args)
    {
        var builder = await TestApplication.CreateBuilderAsync(args);
        
        // Calls our hook
        TimeWarp.Jaribu.TestingPlatform.TestingPlatformBuilderHook
            .AddExtensions(builder, args);
        
        using var app = await builder.BuildAsync();
        return await app.RunAsync();
    }
}
```

### Testing the Integration

Create a test project:

```xml
<!-- Tests/MtpIntegrationTest/MtpIntegrationTest.csproj -->
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net9.0</TargetFramework>
  </PropertyGroup>
  <ItemGroup>
    <ProjectReference Include="../../Source/TimeWarp.Jaribu.TestingPlatform/TimeWarp.Jaribu.TestingPlatform.csproj" />
  </ItemGroup>
</Project>
```

```csharp
// Tests/MtpIntegrationTest/SampleTests.cs
public class SampleTests
{
    [ModuleInitializer]
    internal static void Register() => RegisterTests<SampleTests>();

    public static async Task PassingTest()
    {
        await Task.CompletedTask;
    }

    public static async Task FailingTest()
    {
        await Task.CompletedTask;
        throw new Exception("Expected failure");
    }
}
```

Verify:
```bash
dotnet test Tests/MtpIntegrationTest/
dotnet test --list-tests
dotnet test --filter "Name~Passing"
```
